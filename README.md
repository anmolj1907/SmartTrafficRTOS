# Smart Traffic Light Control System using FreeRTOS

## Project Overview
This project demonstrates RTOS concepts using Arduino and FreeRTOS for traffic signal control.

## RTOS Concepts Used
- Task Management
- Queue
- Priority Scheduling
- Timers

## Hardware Used
- Arduino UNO
- LEDs
- Breadboard
- Jumper Wires

## Software Used
- Arduino IDE
- FreeRTOS Library

## Working
The traffic lights operate using multiple RTOS tasks. Queue communication transfers signal state messages.

## Output
GREEN → YELLOW → RED
